# 川大新生手账

面向四川大学设计学类新生的交互游戏雏形。无依赖静态网页，支持本地存档。

## 像素剧情版本

开场已加入姓名填写及男女主角选择；已有存档首次确认身份后续接原进度。主角和室友阿沐使用同一张统一风格透明角色表 `dist/assets/pixel-player-roommates.png`，阿沐按主角性别切换。周言保留原男同学形象，身份明确为同班同学而非室友。男主为栗棕侧分发型，男阿沐为军绿上衣与卡其裤。

窄屏中立绘下移，对话框覆盖少量脚部，人物介绍独立排在旁边。顶部导航随换行自动撑高。书桌场景与装饰家具改用不同样式名，避免整块剧情被错误地绝对定位。`node identity-checks.cjs` 验证身份输入、男女室友、同学身份、原进度保留、姓名转义及体育课性别限制。

默认首页已改为像素风视觉小说。19个场景、57个选项由《剧情脚本-第一学期.md》编译至dist/story-data.js。逐句对话、结果停留、人物记忆、对话记录、操作节点和学期尾声已接入。课程选择、制服、人脸流程、拼贴工作台继续使用原有功能；既有进度会从首个未完成场景续接，不清除玩家存档。

19 个剧情场景均有独立的像素背景，原图位于 `dist/assets/scenes/scene-01.png` 至 `scene-19.png`，通过 `dist/scene-backgrounds.js` 与剧情对应。宿舍和教室沿用相同空间布置，按剧情改变光线、材料和工具。背景已包含家具及夜景光线，显示时不叠加旧室内装饰或二次变暗。完整提示词与生成方式见《背景绘画说明.md》。打开 `/background-gallery.html` 可逐张查看与下载。`node background-checks.cjs` 检查全部背景覆盖、原图独立性及文件有效性，剧情测试同时检查各场景渲染使用对应背景。

原校园背景和 NPC 立绘保留在 `dist/assets/pixel-campus.png`、`dist/assets/pixel-cast.png`，提示词见《像素素材说明.md》。图片是虚构叙事插画，真实导航仍使用用户地图。

运行node novel-checks.cjs验证剧情任务覆盖、三条完整路径、操作门禁、人物记忆和重复选择保护。该测试不操纵用户浏览器或存档。

## 打开

直接用浏览器打开 `dist/index.html`，或运行 `node preview.mjs` 后打开 http://127.0.0.1:4173 。

## 已实现

- 八章完整流程：入学报到 → 军训 → 正式选课 → 第一次上课 → 设计构成初体验 → 电脑与文件准备 → 比赛与小组合作 → 期末与学期结算。
- 文字选择为主线；后3章9个三选一事件，确定性结算灵感、趣味发量、肝度、模拟GPA，匹配7种学期结局，支持重开。所有属性都是虚构游戏指标，不预测真实身体、成绩或人格。
- 报到当天包含入学手续、人脸录入流程、找寝室、搬行李、购买军训服、认识室友。
- 军训完成后进入正式选课，无试选阶段。13门预置课由截图中的“置入”状态提取；体育课、新中国史是截图中的“选中”课程，由玩家自行选择。
- 1—18周课表切换，保留阶段性专业课程、间断上课和实践周备注。
- 体育课从用户提供的2026—2027学年秋季排课表导入188个真实班次、20个项目，显示课程号、课序号、教师、周次、节次、地点与原表备注。支持项目、星期、关键词和兼容性筛选，每页16个班次；两门特殊体育课需单独申请，不开放选择。未杜撰实时余量、器材要求或原表未注明的性别限制。
- 思政截图真实班次与剧情示例班次分开标注；限制检查、逐周冲突检查、选课结果确认。预置课表沿用此前截图，体育数据年份在体育选课界面单独标明。
- 选择参考、添加/拖动/键盘移动/旋转/删除材料、保存草图、反馈后修改。
- 本地自动存档、角色设置、成长手账导出、作业/社团/比赛/休息时间安排。

## 内容来源与边界

课程数据来自用户提供的三张课表截图。录入全部15门课程（截图总学分33），其中13门预置共30学分，2门自选共3学分。军事技能只记录第1—2周，未虚构节次、地点；思想概论16—17周实践不排课堂；国家安全教育只排第6、10周；人工智能素养两个时间段分别保留。

个人群号与教师姓名没有录入。不会访问真实教务系统、摄像头或采集人脸。人脸录入是角色流程展示，购买军训服未杜撰价格。校园地图使用用户提供的江安校区平面图原图（assets/jiang-an-campus-map.jpg），支持放大至300%滚动查看；任务入口与底图分开，未确认的办理地点不标注为地图坐标。原图红星为图中西南校门标记，不代表角色实时位置。拼贴工作台的参考底图和材料为代码绘制的构图练习资产。

2025级官方通知明确“五史”任选一门2学分、当学期开设前四门；2026级通知使用“选择性思政必修课”课组表述。该原型以用户经历和课表样本为基础，实际推广需按照目标年级更新选课规则。其他选课班次均为剧情示例，非真实排课；对话和具体操作场景为原型叙事，待继续核实。

## 校验

`node checks.cjs` 检查课程总数、学分、课程周次、特殊周排课、逐周冲突和示例班次。

没有构建步骤或外部资源依赖。发布目录为 `dist/`。

## GitHub Pages 发布

项目已包含 `.github/workflows/pages.yml`。将源码推送到 GitHub 仓库的 `main` 分支后，在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。工作流会先检查课表和剧情路线，再发布 `dist/`。首次启用 Pages 后可在 Actions 中手动运行 Deploy game to GitHub Pages。

上线地址以成功部署任务显示的 `github-pages` 链接为准。资源使用相对路径，兼容仓库子路径。存档属于各自浏览器及网站域名，原站点的进度不会自动转移到 GitHub Pages。

发布配置参考：[GitHub Pages 自定义工作流官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
